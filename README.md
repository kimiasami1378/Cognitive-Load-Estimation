# Cognitive-Load-Estimation
This repository contains a **Cognitive Load Estimation Pipeline** that utilizes multi-modal sensor data to estimate cognitive load in real-time. The project involves data preprocessing, feature extraction, and machine learning models to analyze and predict cognitive load states.

## Features

- Multi-modal data processing for cognitive load estimation
- Data preprocessing and cleaning pipeline
- Machine learning-based cognitive load prediction
- Uses physiological signals such as EDA, HRV, and accelerometer data
- Implemented using Python and Colab with GPU acceleration
